The Students Performance Manager API is a backend system designed to help schools efficiently manage students, courses, grades, staff users, attendance tracking, performance analytics, and administrative workflows. It provides a secure, role-based platform for recording academic data and generating insights that support learning outcomes and school operations.

🔐 Core Features

  • User Authentication & Authorization — JWT-based login with role-specific permissions (Admin, Sub-Admin, Teacher).
  • Student Management — Create, update, and fetch student records with contextual school information.
  • Course Management — Register courses and assign them to students or teachers.
  • Grades & Assessment — Upload, update, and view student grades, attendance, library hours, and performance status.
  • Bulk Import System — Background grade imports powered by Celery for efficient asynchronous processing.
  • Analytics Dashboard (API) — Provides insight into pass/fail rates, course difficulty, student performance trends, etc.
  • Error-Standardized Responses — Consistent HTTP error codes and unified JSON response structure.
  • School Context Binding — Automatically binds authenticated user’s school_id and admin_id to every created record.

🛠 Technologies Used

  • Flask — Backend framework
  • SQLAlchemy — ORM for database models
  • Celery + Redis — Background task processing
  • JWT — Secure authentication
  • PostgreSQL/MySQL/SQLite — Database options

📦 API Design Philosophy

This API follows strong software engineering principles:

  • RESTful architecture for predictable routes.
  • Modularization — Routes, models, services, and utilities are clearly separated.
  • Role-based permissions applied through decorators.
  • Standardized error format for easy API consumption by frontends and mobile apps.
  • Scalable grade import workflows to support large schools.

📘 How to Use

API consumers can interact with the system by:

  1. Using endpoints according to their assigned role permissions.
  2. Sending JSON payloads for CRUD operations on students, courses, and grades.
  3. Importing grade spreadsheets through the asynchronous task endpoint.
  4. Consuming analytics endpoints to display dashboards or student insights.
